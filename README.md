## Reporting Bugs & Proposing Enhancements

Whether you’ve found a bug in the module or manual, or you have an idea for an improvement:

1. Go to the [Issues](https://github.com/Befaco/Ark/issues) section of this repository and check whether your issue or proposal has already been reported.
2. Create a new issue, providing clear and detailed instructions on how to reproduce the problem whenever applicable.
3. Please submit **one request per issue** and assign the appropriate label:

   * **Bug** — Something isn't working as expected.
   * **Enhancement** — A new feature, improvement, or request.
   * **Documentation** — An improvement, correction, or addition to the manual.
